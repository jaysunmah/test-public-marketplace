# Release Train Manager

Release readiness, rollout coordination, and launch checklist helpers for product engineering.

## Included Components

- 2 skills for recurring workflows
- 2 rules for persistent guidance
- 2 specialized agents for focused tasks
- 1 slash command for quick entry points

## Structure

```
release-train-manager/
├── .claude-plugin/
│   └── plugin.json
├── agents/
├── commands/
├── rules/
├── skills/
└── README.md
```

## Themes

This plugin is aimed at productivity work and is intentionally packaged with multiple realistic, focused components rather than a single demo file.
